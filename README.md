# PINN-PDE-Testing
A place to consolidate, save and share my personal exploration of PINNs and their applications

With the help of Claude I found materials for the basics of Physics-Informed Neural Networks using Pytorch and have started to create basic models to apply what I have been learning.

So far I have created two simple neural networks to model to a simple harmonic oscillator in 1D and the heat equation in 1D thorugh time, though these only train and model a single initial condition.  Recently I have been working on a PINN to model the 1D heat equation in a more general case for several initial conditions using a DeepONet architecture and hope to have a pre-saved model soon.  In the future I hope to try out more architectures on a few more easy PDEs and eventually create models for the Schrodinger wave equation to visualize how many different potenials vary with time.
